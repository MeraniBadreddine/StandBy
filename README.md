# StandBy

### Time, beautifully still.

A quiet clock for Android.  
Minimal by design. Beautiful by default.

**Version 4.0** · Phone · Free

</div>

---

StandBy turns a screen into a calm place for time — desk, bedside, or charging stand.

No clutter. No noise. Just time, presented with care.

## 4.0

- Phone only  
- Soft night mode (readable in the dark)  
- Quiet defaults (battery and auto-color off)  
- Screensaver activation from the app  
- Fixed digit cells — only changing glyphs move  
- Sensor and timers respect lifecycle  

## Getting started

1. Install the APK  
2. Open StandBy → **+** for settings and colors  
3. Enable system screensaver from the welcome card or Settings → Display → Screen saver  

## Build

```bash
./gradlew assembleDebug
```
